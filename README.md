- 사이트: https://seo7678.github.io/dku-ttak/
- 서버 없음, 추적 없음. 교안·필기는 브라우저 밖으로 나가지 않습니다(직접 붙여넣는 AI 채팅 또는 본인 Gemini 키 호출 제외).
- 진도 찾기는 AI 없이 브라우저에서 계산합니다: 필기한 교안 PDF를 원래 교안과 쪽마다 비교해 필기가 있는 쪽을 찾고, 마지막 필기 쪽을 진도선으로 제안합니다.
- 해설지의 모든 문장은 교안 / 필기 / AI 보충으로 출처를 표시합니다.
- 수업 녹음은 쓰지 않습니다. 교안은 개인 학습용으로만 쓰세요.
- 예시 수업(공학수치해석 3장)은 창작 데이터입니다.
- 테스트: `node --test`
