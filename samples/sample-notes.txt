11/20(목) 수치해석 3주차 — 3장 비선형 방정식의 근
오늘 범위: 구간법(이분법) → 개방법(뉴턴)까지

p.1
f(x) = 0 되는 x 찾기 = 근 찾기. 손으로 못 푸는 식을 컴퓨터로 근사해서 푼다
구간법: 느려도 확실 / 개방법: 빠른데 가끔 엉뚱한 데로 감

p.2
낙하산 문제 → c가 지수 안에도 밖에도 있어서 c로 정리 불가 = 해석해 X
그래프법은 근 위치 감 잡는 용도로만 (소수점 몇 자리까지는 못 감)
열전달·유체 과목에서도 이런 식 많이 나온다고 하심

p.3
중간값 정리: 연속 + f(xl)·f(xu) < 0 → 구간 안에 근 최소 1개 ★중요
중근(x축에 접하는 근)은 부호가 안 바뀜 → 구간법으로 못 잡음
그래프 먼저 그려 보고 초기 구간 잡기. 구간 너무 넓으면 근 2개 들어가서 부호 같아 보일 수 있음

p.4
xr = (xl + xu) / 2
f(xl)·f(xr) < 0 → xu = xr / > 0 → xl = xr / = 0 → xr가 근, 종료
헷갈림!! 기준은 항상 왼쪽 끝 xl이랑 곱한다

p.5
εa = |(새 값 − 이전 값) / 새 값| × 100% — 참값을 모르니까 참오차 대신 근사 상대오차
εa < εs 면 멈춤. 허용오차가 % 단위인지 확인 (0.5 vs 0.5%면 반복 횟수 확 달라짐)
반복 횟수 n = log2(Δx0 / Ea,d) ★시험 나옴 — 손으로 유도해 보기
 → 구간 폭 / 2^n < 원하는 오차, 양변에 로그

p.6
예제 3.1 f(x) = x³ − x − 2, 구간 [1, 2] → f(1) = −2, f(2) = 4 부호 다름 OK
xr: 1.5 → 1.75 → 1.625 … εa 14% → 7% → 4%로 거의 반씩 줄어듦
실제 근 ≈ 1.5214. 엑셀 표 만들 때 εa 첫 칸은 비워 두기 (이전 값 없음)

p.7 가위치법 → 교재로 보기 (넘어감)

p.8
뉴턴-랩슨: x(i+1) = xi − f(xi) / f'(xi)
접선 타고 미끄러져 내려간다고 생각. 초기값 1개, 구간 필요 없음 = 개방법
분모가 f' !! f랑 f' 위치 바꿔 쓰는 실수 매년 나옴 (시험 주의)
f'(x) 미분한 식을 먼저 써 놓고 시작
